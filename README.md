## Built With

- React
- Redux Toolkit
- Tailwind CSS
- GSAP
- Framer Motion

## A Few Details

- Animations are hand-crafted, not AI-generated — GSAP handles scroll-driven and sequenced animations, while Framer Motion handles state- and mount-driven interactions.
- Fully responsive, with a glassmorphic navbar and animated sidebar drawer.
